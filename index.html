Augmented Reality Game
sed condimentum

This game was developed using Unity’s AR dev kit. It was designed to be able to work on any android tablet allowing the player to place blocks of various shapes on top of each other. The shapes once placed could be enlarged or modified using a tailored tool for the system. Once play was begun, the blocks would obey physics and would fall if not properly stacked. The camera would scan the floor in front of the player, creating the play area allowing the player to move in real space around the artificial reality objects in the tablet.

Unity Inventory System Mechanic
sed condimentum

This game was developed using Unity in which an inventory system was implemented which would operate using a series of lists which would track when an item would enter or leave the inventory. The player would add objects by walking over them and removing them when clicking on the relevant object in the inventory. A user interface was designed to display what was in the inventory. The game also had key items to be added to the inventory to access certain areas on the map. Such as a key to open the locked door.

Prototype Level Design
sed condimentum

This game prototype was a project to test level design. It contained enemies which worked using state machines which dictated their behaviors from idle, attack and flee. These behaviors would change in response to specific variables and parameters. The health system was set up using randomly generated integers for each enemy as it was to diversify the strength of the enemy. The level design was following the pattern of a fast-paced platformer/room orientation which kept the player active avoiding "death rays" and projectiles.

Final Year Group University Project
sed condimentum

This was the final group project in university which was a platform game which used many different mechanics. In this project I was primarily in charge of one of 4 levels and testing it rigorously to prove its balanced design and how easy it is to complete it. I was also spearheading the dynamic camera throughout the entire project. Using different occlusion effects and splines to make the camera an active and dynamic as possible. Other dynamic objects in the game were also designed and implemented such as various projectiles and obstacles such as cannons firing giant snowballs.
